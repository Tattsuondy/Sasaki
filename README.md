# 家計簿（画面）

このリポジトリには **画面のプログラムだけ** を置きます。金額・口座名・URL・キーなどのデータは一切置きません。
データは Google スプレッドシートにあり、Google Apps Script（GAS）を通して読み書きします。

## しくみ

- 起動時に、全データを1回の通信で受け取ります。集計・残高・見通しの計算は、すべて画面側（engine.js）で行います。
- 入力や変更は押した瞬間に画面へ反映し、裏でスプレッドシートへ送ります。電波がなくても失われず、つながったときに送ります。
- 端末には、すぐ開けるようにデータの写しを **暗号化して** 置きます（鍵は取り出せない形で端末に作ります）。登録を解除すると消えます。
- 端末の登録は、GAS が出す登録リンクで行います。キーは GAS 側にはハッシュだけを保存します。

## ファイル

| ファイル | 役割 |
|---|---|
| index.html | 画面の土台（外部への通信は Google Apps Script だけに制限） |
| app.js | 画面の動き・同期・端末内の暗号化保存 |
| engine.js | 計算のしかた（GAS の Engine.gs と同じ中身） |
| style.css | 見た目（文字の大きさ・色は「表示の設定」で変更可） |
| sw.js | オフラインでもすぐ開くための仕組み（画面のファイルだけを端末に置く） |
| manifest.webmanifest, icon-*.png | ホーム画面に追加したときのアイコン |

## 更新するとき

1. engine.js を変えたら、GAS の Engine.gs にも同じ中身を貼ります。
2. sw.js の `VERSION` を変えます（端末に古い画面が残らないように）。
